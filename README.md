# 旅程規劃網站

用來呈現、規劃旅行行程的網頁。目前是**不需要帳號的版本**：資料存在瀏覽器裡。

## 怎麼開

直接用瀏覽器（Chrome / Edge）打開 `index.html` 就能用，需要網路連線來載入地圖。

## 功能

- 多份旅程，每份有封面、旅程簡介、行程概要和總覽地圖（每天一個顏色和範圍色塊）
- 每日頁：餐食安排、交通安排（東京各路線標籤）、今日地點和地圖 ①②③
- 餐食方案：每一餐可放多個餐廳備案（評分、預算、公休、營業時間、距離車站、備註），拖曳排序；地圖上以「午A、晚B」標示
- ☆ 選定的餐廳會自動加入今日地點（標「★ 午餐」），早餐放前面、晚餐放最後、午餐插在最順路的位置；改選會在同位置替換，取消選定或刪除備案會一起移除，編輯備案會同步店名／位置／照片。「→」則是另外手動加一份（不連動）
- 新增地點：一個搜尋框可輸入店名、地址、Google 地圖網址、手機「分享」的文字（店名＋短網址）或座標；也可在地圖上點選
- 「在 Google 地圖找 ↗」：在旁邊開 Google 地圖，點選店家後按 Ctrl+L、Ctrl+C 複製網址，回到這裡會自動讀剪貼簿帶入（第一次要允許讀取剪貼簿；不允許時按 Ctrl+V 貼上即可）。最準，不需要金鑰
- 搜尋來源：預設免費（Photon／OpenStreetMap＋國土地理院；放上網站後再加 Nominatim）。在「⚙ 搜尋設定」貼上自己的 Google Places API (New) 金鑰，就會用 Google 搜尋，選定後自動帶入評分、營業時間、公休日。金鑰只存在瀏覽器，不會匯出
- 航班：去程／回程卡片，填機場代碼（TPE、NRT…）和當地時間後自動算飛行時間（已扣時差）
- 住宿：入住／退房、晚數、價格、附近車站、備註；🔒 私密資訊（門鎖密碼等）瀏覽時預設隱藏；有位置的住宿會以 🏠 出現在總覽地圖
- 行前準備：可分類的勾選清單、進度條，拖曳可跨分類移動
- Tab 自動填入：咖啡色斜體的提示字按 Tab 填入；打字時用這趟用過的內容自動補完，按 Tab 接受、Esc 取消
- 複製地點：⧉ 複製到這個地點後面；⇄ 可移到或複製到其他天（住宿預設是複製）；住宿頁有位置的住宿可一鍵加入。地圖上同一位置會合併成「1・4・6」
- 交通路線依地區：總覽 → 編輯模式 →「交通路線」可選自動判斷／東京／大阪／福岡／其他地區；另有通用交通方式和「自訂路線」（自己填代號、名稱、顏色）。要加新城市請改 `js/lines.js`
- 拖曳 ⋮⋮ 調整順序，⇄ 把地點移到其他天，在地圖上拖曳標記可修正位置
- 右上角「編輯模式」切換瀏覽和編輯；用 `*星號*` 包住的字會顯示成咖啡色重點字
- 照片：在景點或餐廳的編輯視窗直接 Ctrl+V 貼上、拖曳或選檔；自動壓縮成長邊 1400px 的 JPEG。景點 1 張、餐廳 3 張
- 匯出行程檔（`.trip.json`）備份，可在首頁匯入；照片會一起打包
- 匯出 PDF：行程頁右上角「匯出 PDF」→ 16:9 版面（封面、簡介、概要、總覽地圖、航班、住宿、行前準備、每日餐食交通、路線大地圖、景點卡片、餐食方案），可勾選要印的內容和天數；私密資訊預設不印。等「地圖都載入了」再按列印，目的地選「另存為 PDF」

## 注意

- 資料只存在**這台電腦的這個瀏覽器**。換電腦或清除瀏覽器資料前，請先匯出行程檔。
- 範例行程的座標是大約位置，可以在地圖上拖曳標記修正。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面入口 |
| `css/style.css` | 版面與風格 |
| `js/store.js` | 資料儲存（之後換成 Firebase 只需替換這個檔案） |
| `js/photos.js` | 照片壓縮與儲存（瀏覽器 IndexedDB；之後換成 Google Drive 只需替換這個檔案） |
| `js/app.js` | 畫面與互動 |
| `js/lines.js` | 各地區交通路線（東京、大阪、福岡＋通用），可自行增加城市 |
| `js/sample.js` | 範例行程「東京秋日文青慢遊記」 |
